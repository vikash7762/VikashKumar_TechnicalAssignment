# AI Usage Disclosure

## 1. AI Tools Used

ChatGPT was used as an assistance tool during the development of the Sales Order and Inventory Management System.

## 2. Tasks Where AI Assistance Was Used

- Assistance with designing and improving the FastAPI backend structure.
- Help with SQLAlchemy models, Pydantic schemas, and REST API implementation.
- Assistance with frontend HTML, CSS, and JavaScript functionality.
- Help with sales order calculations, discount handling, stock updates, and validation.
- Assistance with documentation, SQL queries, and debugging.

## 3. Representative Prompts

1. "Help me implement a Sales Order and Inventory Management System using FastAPI, MySQL, and a frontend."
2. "Provide the complete updated code for handling sales orders with multiple products, discount calculations, confirmation, cancellation, and stock movements."
3. "Help me prepare the required SQL queries and project documentation for the technical assignment."

## 4. Review and Verification

AI-generated suggestions were reviewed and adapted to the existing project structure. The application was run locally, and implemented features were checked through the frontend and API.

The developer remains responsible for the final code, configuration, testing, and submission.

## 5. Issues Identified and Corrected

During development, the sales order calculation and data structure needed improvements to support discount percentages, discount amounts, subtotals, and final payable amounts.

The backend models, schemas, order API, and frontend order form were updated to support these calculations.

## 6. Limitations

AI-generated code may require adjustments depending on the actual database schema, installed package versions, and project configuration. Final verification should be performed in the local development environment.
